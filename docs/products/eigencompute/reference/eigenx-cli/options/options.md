The EigenX CLI is the CLI toolkit for building and managing applications using EigenCompute.

This reference describes EigenX CLI options.

## Options 

### `verbose`

```
--verbose==<true|false>
```

Enable verbose logging. The default is `false`.

### `enable-telemetry`

```
--enable-telemetry=<true|false>
```

Enable telemetry collection on first run without prompting. The default is `false`.

### `disable-telemetry`

```
--disable-telemetry=<true|false> 
```

Disable telemetry collection on first run without prompting. The default is `false`.

### `help`

```
--help
```

Displays help for EigenX CLI.
