Manage telemetry settings.

### Synopsis

`eigenx telemetry [--enable] [--disable] [--status]`

### Options

`--enable` (boolean)

> Enable telemetry collection. Default is false.

`--disable` (boolean)

> Disable telemetry collection. Default is false.

`--status` (boolean)

> Show current telemetry status. Default is false.
