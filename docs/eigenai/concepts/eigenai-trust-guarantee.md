title: Trust Guarantees
sidebar_position: 3
---

EigenAI enables verifiable trust guarantees for your AI responses. Use EigenAI to verifiably guarantee no hidden modifications
to the model.

EigenAI provides deterministic execution so if EigenAI claims a specific model is providing a response, someone else can 
run the model with the same input and get the same output as EigenAI. If the model weights have been modified, the results
won't match and the claim of the model being unmodified is provably false.
